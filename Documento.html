Resumo

Este repositório contém uma biblioteca JavaScript chamada npm-files, cuja finalidade é listar e acessar arquivos publicados de um pacote npm.

Descrição do projeto

O pacote permite recuperar os arquivos de um módulo do npm, emitindo eventos para cada arquivo, com informações como caminho, tamanho, data de modificação e conteúdo.

Exemplo de uso

var files = require('npm-files');

files('intersect')
  .on('file', function(file) {
    console.log(file.props);
    file.pipe(process.stdout, { end: false });
  })
  .on('end', function() {
    console.log('end');
  })
  .on('error', function(err) {
    throw err;
  });

API

files(name[, opts])

Cria um EventEmitter que emite um evento file por arquivo do módulo e end ao fim do processo.

files#on('file', fn)

Emite um stream legível com a propriedade props, incluindo:

  • path
  • size
  • mtime
  • cksum

files#on('end', fn)

Indica que a operação terminou.

files#on('error', fn)

Emite erro caso algo falhe.

Instalação

$ npm install npm-files
